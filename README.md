# Amazon Sales EDA Project 🛒📊

## Описание проекта
Данный проект представляет собой **разведочный анализ данных (EDA)** датасета продаж на Amazon. Цель проекта — подготовить «грязные» данные, очистить их от лишних символов и провести статистический и визуальный анализ ключевых метрик: цен, размера скидок, рейтингов товаров и популярности различных категорий. 

Этот проект демонстрирует навыки Data Cleaning, Data Visualization и выявления базовых бизнес-инсайтов (соотношение скидок и рейтинга, самые рейтинговые категории и т.д.).

## 🧹 Очистка данных (Data Cleaning)
В ходе подготовки данных были выполнены следующие шаги (см. ноутбук `amazon_eda.ipynb`):
1. **Преобразование цен**: Удалены символы валюты индийской рупии (`₹`) и запятые-разделители разрядов. Строковые значения переведены во `float`.
2. **Преобразование скидок**: Удален символ процентов (`%`), значения конвертированы в числовой формат.
3. **Очистка количества отзывов** (`rating_count`): Удалены запятые.
4. **Обработка аномалий**: При конвертации рейтинга (`rating`) учтены мусорные текстовые вставки (например, `|`), они преобразованы в `NaN` для дальнейшей безопасной работы алгоритмов.

## 📈 Визуализации и анализ

В 노트북е реализованы следующие ключевые визуализации:

### 1. Распределение цен и скидок (Univariate Analysis)
Мы смотрим на распределение цен (с использованием логарифмической шкалы для сглаживания очень дорогих товаров) и гистограммы размеров скидок для ответа на вопрос: *какие скидки чаще всего дает платформа?*

> 📊 **Ожидаемый график**: Гистограмма (Histogram/KDE) цен и рейтингов, показывающая, что большинство товаров лежат в диапазоне рейтинга 3.8 - 4.5.

### 2. Влияние скидки и цены на рейтинг (Bivariate Correlation)
Построен Scatter plot (точечный график), чтобы визуально определить:
- Связано ли наличие огромной скидки с плохим качеством товара (или, наоборот, с высоким рейтингом)?
- Влияет ли базовая стоимость товара на оценку пользователей?

> 📊 **Ожидаемый график**: Матрица рассеяния (Scatter plots) + Матрица корреляций Пирсона (Heatmap), где видно числовые коэффициенты взаимосвязи.

### 3. Анализ популярных категорий
Из строкового дерева категорий (например, `Computers&Accessories|Accessories&Peripherals...`) извлекается **Главная категория** (Main Category). 
Строятся два ключевых графика (Barplots):
- Топ-10 главных категорий по количеству выставленных товаров в магазине.
- Топ категорий по наивысшему среднему рейтингу.

> 📊 **Ожидаемый график**: Горизонтальный столбчатый график (Horizontal Bar Plot), который наглядно сортирует категории по среднему баллу пользователей.

## 🚀 Как запустить проект локально

1. Убедитесь, что у вас установлен Python (рекомендуется создать виртуальное окружение `venv`).
2. Установите зависимости:
   ```bash
   pip install pandas numpy matplotlib seaborn notebook
   ```
3. Скачайте файл датасета `amazon.csv` (он должен лежать в корне вместе с ноутбуком).
4. Запустите Jupyter Notebook / откройте файл в VS Code:
   ```bash
   jupyter notebook amazon_eda.ipynb
   ```
5. В интерфейсе выполните "Run All" (Запустить всё).
